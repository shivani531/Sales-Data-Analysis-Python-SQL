# Sales Data Analysis

## Project Description
This project analyzes sales data to identify the best-selling products, monthly revenue trends, and top-performing regions.

The project uses Python, Pandas, SQL, SQLite, and Matplotlib to calculate business metrics and create visual insights.

## Tools Used
- Python
- Pandas
- SQL
- SQLite
- Matplotlib
- Google Colab

## Dataset
The dataset contains sales records with the following columns:

- order_id
- order_date
- region
- product
- category
- quantity
- unit_price
- revenue

Revenue was calculated as:

revenue = quantity × unit_price

## Analysis Performed
- Checked for missing values and duplicate records
- Calculated total revenue and total units sold
- Identified the highest-revenue product
- Identified the month with the highest sales
- Identified the best-performing region
- Created a monthly revenue visualization

## Key Results
- Total Revenue: ₹5,865
- Total Units Sold: 42
- Unique Orders: 12
- Highest Revenue Product: Laptop
- Highest Sales Month: January 2026
- Best Performing Region: North

## Project Process
1. Created a sales dataset using Python and Pandas.
2. Added a revenue column using quantity and unit price.
3. Checked the dataset for missing values and duplicates.
4. Loaded the data into SQLite.
5. Used SQL queries to analyze product, monthly, and regional sales.
6. Created a bar chart of monthly revenue using Matplotlib.
7. Saved the dataset and analysis results as CSV files.
